Atualmente, venho aprofundando meus conhecimentos em **microsserviços, mensageria, autenticação e qualidade de software**.

## 🚀 Projetos em destaque

### 🎓 [Sistema de Gestão Escolar](https://github.com/gustavo-limaa/Sistema_basico_de_escola)
Sistema de gestão escolar desenvolvido com foco em **Clean Architecture**, regras de negócio e segurança. Inclui autenticação com **ASP.NET Core Identity e JWT**, controle de acesso por roles/claims e persistência com Entity Framework Core.

**Destaques:** Soft Delete com filtros globais do EF Core e testes com xUnit, Moq, FluentAssertions, Bogus e Respawn.

### 🛒 [E-commerce com Microsserviços](https://github.com/gustavo-limaa/ecommerce-microservices-net)
Meu segundo projeto em destaque: um ecossistema de e-commerce em .NET com serviços separados para autenticação, pedidos, catálogo e processamento de pagamentos. Integra **API Gateway com YARP**, **RabbitMQ** para eventos assíncronos e **Docker Compose** para executar o ambiente local.

**Destaques:** arquitetura orientada a eventos, autenticação com JWT, persistência com Entity Framework Core e MySQL, além de testes unitários e de integração.
